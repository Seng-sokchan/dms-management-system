Install on Android

  1. 1 Download the APK using the button above.
  2. 2 If prompted, allow installs from your browser or file manager (Install unknown apps).
  3. 3 Open the downloaded file and tap Install.
  4. 4 Launch DMS Mobile and sign in with your account.
The APK file must be built and copied to this folder before the download link works. See website/README.md for build instructions.
